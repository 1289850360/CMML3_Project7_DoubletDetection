# CMML3 Project 7: Benchmarking Doublet Detection Methods

This repository contains the code used for my CMML3 Project 7 report. The project benchmarks three doublet detection methods, DoubletFinder, Scrublet and scDblFinder, using the labelled PBMC dataset from GSE96583. Demuxlet singlet/doublet annotations were used as ground truth.

## Input data

The raw and supplementary files were downloaded from GEO accession GSE96583. The analysis used batch 2 files, including:

- GSM2560248_2.1.mtx.gz
- GSM2560248_barcodes.tsv.gz
- GSM2560249_2.2.mtx.gz
- GSM2560249_barcodes.tsv.gz
- GSE96583_batch2.genes.tsv.gz
- GSE96583_batch2.total.tsne.df.tsv.gz

These input data files are not included in this repository because of file size and data-management reasons. They should be downloaded separately from GEO and placed in the same project directory before running the scripts.

## Script overview

### 01_R_DoubletFinder_only.R

This script reads the GSE96583 batch 2 count matrix and metadata, cleans the demuxlet labels, removes ambiguous cells, creates a Seurat object, performs preprocessing and runs DoubletFinder. It also exports the filtered count matrix and metadata for Scrublet.

Main outputs include:

- metrics_DoubletFinder.csv
- counts_for_scrublet.mtx
- metadata_for_scrublet.csv
- seurat_object_DoubletFinder_only.rds

### 02_Python_scrublet.py

This script runs Scrublet in Python using the count matrix exported from the Seurat object. It calculates benchmark metrics against the demuxlet singlet/doublet labels.

Main outputs include:

- metrics_scrublet.csv
- scrublet_predictions.csv

### 03_R_final_figures.R

This script was used to combine the initial DoubletFinder and Scrublet results and generate preliminary benchmark figures and tables. It is kept here for transparency, although the final report uses the three-method comparison generated by script 05.

### 04_R_scDblFinder.R

This script loads the processed Seurat object, runs scDblFinder and calculates precision, recall, F1 score, AUROC and AUPRC using demuxlet labels as ground truth.

Main outputs include:

- metrics_scDblFinder.csv
- seurat_object_with_scDblFinder.rds

### 05_R_redraw_with_scDblFinder.R

This script combines the results from DoubletFinder, Scrublet and scDblFinder. It generates the final benchmark table, UMAP comparison figure and supplementary score-distribution figure used in the report.

Main outputs include:

- final_benchmark_metrics_3methods.csv
- Figure1_UMAP_4methods.png
- Figure2_benchmark_metrics_3methods.png
- Supp_score_distributions_3methods.png

## Software environment

The R analysis was run in RStudio. The main R packages used were:

- Seurat
- DoubletFinder
- scDblFinder
- ggplot2
- patchwork
- dplyr
- tidyr
- readr
- pROC
- PRROC

Scrublet was run in a separate conda environment using Python 3.10. The main Python packages used were:

- scrublet
- numpy
- pandas
- scipy
- scikit-learn
- matplotlib

Example conda setup for Scrublet:

conda create -n scrublet_env python=3.10 -y
conda activate scrublet_env
conda install -c conda-forge -c bioconda scrublet -y

## Reproducibility

To reproduce the analysis:

1. Download the GSE96583 batch 2 files from GEO.
2. Place the input files in the project directory.
3. Run `01_R_DoubletFinder_only.R` in RStudio.
4. Activate the Scrublet conda environment and run `02_Python_scrublet.py`.
5. Run `04_R_scDblFinder.R` in RStudio.
6. Run `05_R_redraw_with_scDblFinder.R` to generate the final figures and tables.

The final report used demuxlet singlet/doublet labels as the benchmark ground truth. Cells labelled as ambiguous were removed before evaluation.
